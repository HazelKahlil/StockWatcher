# 第一次使用

1. 把整个 ZIP 解压到普通文件夹；不要在压缩包预览里直接运行。
2. 双击根目录唯一主入口 **启动 StockWatcher.vbs**。
3. 启动器先只读确认完整应用树、原生 Preflight、UI 入口和运行依赖；缺少任何一项都会给出中文提示并停止，不会联网补装。
4. 启动器只接受数字签名有效、发布者匹配 Python Software Foundation 的 64 位 Python 3.12/Pythonw，并只定位数字签名有效且发布者匹配官方公司的 `TdxW.exe`。请先由本人通过官方终端自身的正常入口完成启动、登录并开启 TQ，不要把密码、验证码交给 StockWatcher。
5. 原生 Preflight 会写入固定 schema 的 `%LOCALAPPDATA%\StockWatcher\reports\tdxquant-preflight.json`。只有整体 `PASS`、恰好一个 `api_session=PASS` 且 `windows_live_verified=true` 时，才启动包内真实 StockWatcher PySide6 UI；任何缺失、重复、畸形或供应商非零结果都停止，且不会自动启动 `TdxW.exe` 或请求管理员权限。

## 退出、再次启动和卸载

- 关闭 StockWatcher 窗口即退出；重复双击不会打开第二个实例。
- 再次使用时仍双击 **启动 StockWatcher.vbs**。
- 卸载：先关闭程序，再删除本便携目录。
- 运行数据、报告和备份若由其他 StockWatcher 版本写入 `%LOCALAPPDATA%\StockWatcher`，不会随便携目录删除。确认已备份且不再需要后再由本人手动处理。

## 已知限制

- 本包是当前单机内部便携候选，不是无需前置环境的外部客户便携版。包内包含完整 `stock_watcher` 应用源码、UI 和原生 Preflight，但不携带 Python 或第三方运行时。
- 目标机必须预先具备已允许执行的 python.org 官方签名 64 位 Python 3.12、官方 TdxQuant `tqcenter` 模块，以及按包内 `app/uv.lock` 准备的 PySide6 6.11.1、Pydantic 2.13.4、PyYAML 6.0.3、tzdata 2026.3 及其锁定传递依赖。准备工作在交付前由管理员完成；主入口只读检查，不调用 pip。
- 不会联网安装依赖，也不会关闭或绕过 Application Control、Defender、UAC、TLS、执行策略或其他安全控制。若脚本被组织策略阻止，请停止并联系机器管理员。
- 入口不会自动启动官方终端，也不会请求提权。终端未运行、未登录或 TQ 未就绪时只会中文 fail-closed；请通过官方终端自身的正常入口处理后重试。
- 原生 Preflight 通过只说明固定环境和 TQ 股票列表接口检查通过，不代表紫黄线、字段授权、性能、完整交易时段 M0、Windows 通知或公开发布已验证。
- 在 M0 完成前，候选生成和资金模块始终关闭；本包不读取交易账户、密码、验证码、持仓、订单，也没有下单能力。
