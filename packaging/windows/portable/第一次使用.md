# 第一次使用

1. 把整个 ZIP 解压到普通文件夹；不要在压缩包预览里直接运行。
2. 双击根目录唯一主入口 **启动 StockWatcher.vbs**。
3. 如果通达信尚未运行，StockWatcher 只会尝试启动“数字签名有效且发布者匹配官方公司”的 `TdxW.exe`。请在官方终端内由本人完成登录，不要把密码、验证码交给 StockWatcher。
4. 回到 StockWatcher 点 **重新检测**。只有 `127.0.0.1:17709` 返回最小只读股票列表，且请求明确包含 `{"market":"5","list_type":0}` 时，界面才显示“TQ 已连接”。
5. 可在界面内创建当前用户的桌面快捷方式；不需要管理员权限，不注册服务、不自动启动、不修改 PATH 或系统安全策略。

## 退出、再次启动和卸载

- 关闭 StockWatcher 窗口即退出；重复双击不会打开第二个实例。
- 再次使用时仍双击 **启动 StockWatcher.vbs**。
- 卸载：先关闭程序，再删除本便携目录和可选桌面快捷方式。
- 运行数据、报告和备份若由其他 StockWatcher 版本写入 `%LOCALAPPDATA%\StockWatcher`，不会随便携目录删除。确认已备份且不再需要后再由本人手动处理。

## 已知限制

- 本包供当前单机内部自用，依赖目标机已允许执行的 python.org 官方 64 位 Python 3.12（含 Tcl/Tk）和 Windows 自带组件；包内不携带解释器或第三方运行时。
- 不会联网安装依赖，也不会关闭或绕过 Application Control、Defender、UAC、TLS、执行策略或其他安全控制。若脚本被组织策略阻止，请停止并联系机器管理员。
- 最小只读检查通过只说明当前 TQ 股票列表接口可用，不代表紫黄线、字段授权、性能、完整交易时段 M0、Windows 通知或公开发布已验证。
- 在 M0 完成前，候选生成和资金模块始终关闭；本包不读取交易账户、密码、验证码、持仓、订单，也没有下单能力。
