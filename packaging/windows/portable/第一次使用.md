# 第一次使用

1. 把整个 ZIP 解压到普通文件夹；不要在压缩包预览里直接运行。
2. 双击根目录唯一主入口 **启动 StockWatcher.vbs**。
3. 启动器先只读确认完整应用树、原生 Preflight、UI 入口和运行依赖；缺少任何一项都会给出中文提示并停止，不会联网补装。
4. 启动器只接受数字签名有效、发布者匹配 Python Software Foundation 的 64 位 Python 3.12/Pythonw。
5. 正常启动进入 Tushare 数据闸门，不要求通达信。打开 **设置 → 数据接口**，由本人在
   隐藏输入框输入新换发凭据；测试成功并确认后才保存到 Windows Credential Manager。
6. TdxQuant 仅保留为可选诊断；诊断失败不会阻止 Tushare 正常启动。

## 退出、再次启动和卸载

- 关闭 StockWatcher 窗口即退出；重复双击不会打开第二个实例。
- 再次使用时仍双击 **启动 StockWatcher.vbs**。
- 卸载：先关闭程序，再删除本便携目录。
- 运行数据、报告和备份若由其他 StockWatcher 版本写入 `%LOCALAPPDATA%\StockWatcher`，不会随便携目录删除。确认已备份且不再需要后再由本人手动处理。

## 已知限制

- 本包是当前单机内部便携候选，不是无需前置环境的外部客户便携版。包内包含完整 `stock_watcher` 应用源码、UI 和原生 Preflight，但不携带 Python 或第三方运行时。
- 目标机必须预先具备已允许执行的 python.org 官方签名 64 位 Python 3.12，以及按包内
  `app/uv.lock` 准备的 PySide6、Pydantic、PyYAML、tzdata、requests、keyring、
  Tushare、pandas、NumPy、lxml 及锁定传递依赖。
  只有可选 TdxQuant 诊断需要官方 `tqcenter`。
- 不会联网安装依赖，也不会关闭或绕过 Application Control、Defender、UAC、TLS、执行策略或其他安全控制。若脚本被组织策略阻止，请停止并联系机器管理员。
- 入口不会自动启动官方终端，也不会请求提权。
- Tushare 连接测试只说明一个小请求成功，不代表分钟、板块、时间戳、连续性能或 M0 已通过。
- 在 Tushare M0 完成前，候选生成和资金模块始终关闭；本包不读取交易账户、密码、验证码、持仓、订单，也没有下单能力。
