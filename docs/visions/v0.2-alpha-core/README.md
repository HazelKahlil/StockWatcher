# v0.2-alpha-core：交付可回放的 M1 Alpha 核心流程

> 状态：计划中
> 创建：2026-07-22 ｜ 计划 tag：`v0.2.0`

## 目标与范围

- 实现股票池与排除、全市场价格/涨速、板块共振、三日趋势、固定三只和“强/中/近”。
- 实现 Replay/Synthetic、健康状态、SQLite 基础、09:45/14:50 和右下角桌面弹窗。
- 若 M0 资金能力未通过，界面必须显示“资金模块未就绪”，不得冒充完整 V1。
- 不在本版交付盘中完整紫黄线异动、iPhone、完整历史/反馈/总结、稳定安装包或自动调参。

## 依赖

- v0.1 至少给出价格、板块、历史的可执行路线；若结论限制 M1，范围必须同步降级。
- 代码结构、测试/lint/类型检查命令在开工 PR 中补入 `AGENTS.md` 和 `pyproject.toml`。

## 验收标准

- [ ] 锁定股票池排除项有单元测试，固定三只在 0/1/2/3+ 完整信号场景正确。
- [ ] 相同 Replay 输入与配置得到完全相同的候选、等级、原因和提醒事件。
- [ ] 价格很强但板块弱最多为“近”；核心数据断开时停止新候选并正确预热恢复。
- [ ] 09:45/14:50 固定提醒、同股冷却、无变化不重复和三四名防抖通过回放。
- [ ] Windows 弹窗一窗三行、右下角、不抢焦点、手动关闭、轻声音通过目标机验收。
- [ ] 基础 SQLite、日志、配置版本和健康指标可追溯，未保存凭证。
