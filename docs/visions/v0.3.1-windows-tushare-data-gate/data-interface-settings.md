# “数据接口”设置说明

打开 StockWatcher，选择 **设置 → 数据接口**。

- 超级接口：默认主接口。
- 快速接口：只有比较 M0 通过的静态/历史 API 可启用。
- 智能路由：遵守允许列表；实时链不会无条件 fallback。
- Mock / Replay：仅回放，不等于真实数据。
- 通达信诊断模式：可选诊断，不影响正常启动。

输入服务地址和 Human Owner 新换发的 Key/Token，选择是否使用系统代理，再点击“测试连接”。
输入框默认隐藏，TLS 始终开启。测试失败不修改旧凭据、不重启应用，也不开候选门。
只有测试成功后才可“保存并切换”，且仍需 Human Owner 二次确认。
