## 为什么普通 SDK 路线没有直接生成

本机实际执行了供应商文档指定的 Tushare SDK 配置。服务端对
`stock_basic` 返回 HTTP 429：`请求次数超限（每分钟最多120次），请稍后再试`。
Tushare 1.4.29 的 `DataApi.query()` 使用 `if res:` 判断响应；`requests` 会把 429
响应判为 false，因此 SDK 静默返回空 DataFrame，表面上像“成功但 0 行”。原始 HTTP
检查确认它不是收盘数据缺失、日期错误或 Token 被删除，而是服务端限频。

为避免继续撞限频，已停止运行中的 StockWatcher Dev 进程，并使用已授权、独立保存的
Super 静态接口生成本报告。普通 `fastapic` 主路线仍需在冷却且无其他设备占用同一凭据时
重新验证。
