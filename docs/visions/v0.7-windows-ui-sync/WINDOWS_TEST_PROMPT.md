1. 先只读核实现在运行的 StockWatcher 路径、版本、进程数、窗口数据时间和 Windows/DPI。中国交易日 09:25–15:35 不安装、不覆盖、不退出或杀死正在看盘的 App。此时只做现状核查、下载准备和独立临时目录里的代码测试，安装与退出测试等收盘后继续。
2. 从本 PR 最新 head 的成功 Governance 下载 `stockwatcher-windows-py3.12` 制品（失败不能改用旧包冒充）。检查 ZIP 内版本、安装包 SHA256、解压后 `SOURCE_COMMIT` 与 PR head 一致。不要仅相信文件名。若制品已过期，在隔离 checkout 用锁定依赖执行项目 Build，记录本地重建证据。
3. 允许安装前先备份 `%LOCALAPPDATA%/StockWatcher` 的数据库、报告和配置，备份不上传 GitHub。运行时备份数据库必须用 SQLite backup API；不能只复制活库主文件而忽略 WAL。完整性检查只对备份执行。保留原安装包和回退路径，凭证留在 Credential Manager，不打印或导出 Token。

5. 非交易时段测试标题栏 X、Ctrl+Q、扫描中关闭、报告读取/生成中关闭；应及时退出且无残留进程。再次启动、重复启动只保留一个主实例。不要测试真实下单或连接交易账户。旧版本近期已修复关闭、单实例和预热停滞，本次必须确认没有回归。
