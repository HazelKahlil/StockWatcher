# v0.4-v1-feature-complete：完成真实数据路线上的 V1 功能

> 状态：计划中
> 创建：2026-07-22 ｜ 计划 tag：`v0.4.0`

## 目标与范围

- 在 v0.3 可执行结论上接入真实资金/板块数据、开盘/重连假跳过滤和盘中特别强异动。
- 交付目标环境桌面提醒、iPhone 辅助通知、详情/历史、反馈、每日总结、CSV/JSON 导出与每日备份。
- 保持盘中规则确定性；自动软参数优化和涨停封单风险提醒不在本版。
- 本版达到功能完整，不等于稳定发布；安装与长时间试用由 v0.5 承接。

## 依赖

- v0.2 本地核心排名、提醒状态机、Replay 和健康降级已封版。
- v0.3 对真实数据给出 PASS 或足够明确的 PASS_WITH_LIMITS；若 FAIL，本版必须重新规划而非绕过。

## 验收标准

- [ ] 真实数据原值、单位、变化、同步/背离、质量与 provider 版本随提醒保存并可回放。
- [ ] 盘中特别强异动源时间到弹窗 ≤10 秒，最多 3 批/日；冷却、合并与防抖正确。
- [ ] 开盘、午休、断网和重连不会产生假跳提醒。
- [ ] 桌面先发、iPhone 异步；失败降级且不泄露设备密钥。
- [ ] 历史 31 天、反馈、每日/次日总结、导出和每日备份可用。
- [ ] `docs/reference/v2.0/acceptance_tests.md` 中除安装/长期稳定化外的适用 UAT 有目标环境证据。
