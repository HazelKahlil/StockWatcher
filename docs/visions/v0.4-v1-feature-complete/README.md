## 2026-07-29 盘后真实数据回放

本次只验证真实日线回溯与总结呈现，不把盘后数据表述为盘中扫描、固定提醒或强异动证据。
主产品 `fastapic` 路线在回放阶段持续返回 `rate_limited`，因此按既定边界只在高级诊断中
使用旧 Super 静态接口获取当日与前三个交易日数据；该回退不能证明 V1 生产实时路线可用。

- 有效证券 5,516 只：上涨 4,248、下跌 1,212、平盘 56，上涨比例 77.0%，中位涨幅
  +1.58%。
- 北交所 326 只参与统计但不进入默认候选；沪市主板、深市主板、创业板、科创板按 V1
  规则参与回溯观察。
- 强势行业包括乳制品、超市连锁、软饮料、铅锌、特种钢、焦炭加工和百货。
- 回溯 Top3：欢乐家 `300997.SZ`（软饮料，+20.00%）、东百集团 `600693.SH`
  （百货，+9.99%）、国芳集团 `601086.SH`（百货，+9.96%）；同一行业不超过两只。
- 静态回退没有可用的 moneyflow/盘中资金字段，资金统一按 0 分并标记“资金未确认”；
  候选仍正常生成。
- 回放不生成或声称 1/3/5 分钟涨速、盘中资金增强、09:45/14:45 或强异动证据。
