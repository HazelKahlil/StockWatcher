# v0.3-windows-data-gate：取得真实数据与授权结论

> 状态：计划中（环境待定）
> 创建：2026-07-22 ｜ PASS/PASS_WITH_LIMITS 后计划 tag：`v0.3.0`

## 目标与范围

- 若继续原规格路线：在真实 Windows + 通达信/TdxQuant 环境验证全市场行情、三日历史、板块、紫黄线、批量性能、重连和授权。
- 若决定使用合法的 Mac 兼容数据源：开工前先由业务负责人确认数据口径与授权，并重命名/重写本版本，不能静默把替代字段当通达信紫黄线。
- 交付可重复运行的 `m0_probe`、字段/版本元数据与 `M0_report.md`。
- 结论只能是 PASS、PASS_WITH_LIMITS 或 FAIL；FAIL 不用网页抓取、OCR 或鼠标脚本绕过。

## 开工门

- [ ] 人类 owner 明确最终路线：Windows 虚拟机、云机、实体机，或获授权的 Mac 兼容数据源。
- [ ] 记录目标环境、软件/SDK、账号授权与成本；无法取得真实环境时本版本保持计划中，不伪开工。
- [ ] 本版本登记为活跃并写入本地 `main`；创建关联执行 issue。
- [ ] 读取 `rules/data.md`、`rules/security.md` 与 `boundaries.md`。

## 验收标准（必须可检查）

- [ ] 完成 `docs/reference/v2.0/m0_checklist.md` 的适用检查并附真实环境证据。
- [ ] 若使用通达信：至少 3 只股票每 5 秒比对界面与程序值，连续 ≥30 分钟；紫黄线在显示精度内一致率 ≥98%，或明确 FAIL/限制。
- [ ] 全市场基础快照新鲜度、全扫描、TopN 深度计算和端到端延迟有 p50/p95、错误率与环境信息。
- [ ] 板块、三日历史、开盘/午后/断网重连与一个完整交易时段有结果。
- [ ] 授权结论覆盖内部 2—3 人、本地展示、历史保存及公式/Level-2 或替代供应商使用。
- [ ] `M0_report.md` 的每个限制映射到降级路线、owner 和下一触发点。
- [ ] Provider 归一化、时间戳、去重、stale/STOPPED/WARMING 与 Replay 回归测试通过。
