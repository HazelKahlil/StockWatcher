| 区域 | 路径/范围 | 为什么危险 | 动它之前必须 |

| 跨环境结论 | Mac Replay/UI/性能结果与 Windows/通达信行为 | 不同 SDK、窗口系统、时钟和打包环境可能产生完全不同结果 | 在证据中标注 OS、版本和数据源；Windows 结论必须来自真实 Windows 环境 |

| Schema 与真实数据 | migrations、retention、backup、restore | 可能破坏历史、反馈和可追溯证据 | 备份、可逆迁移、数据量验证和人类确认 |

| 发布与安装 | Windows installer、auto-start、升级/回滚 | 会改变用户机器和持续运行行为 | 目标 Windows 测试、签名/来源说明、卸载与回滚验证 |
